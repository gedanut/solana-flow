# Solana Flow

A local-first workbench for analysts inspecting exact Solana net balance evidence. Workflow: import/capture -> query -> inspect uncertainty/source evidence -> compare -> export. Browser app runs on loopback; public static explorer is read-only synthetic. Audience: Python/data engineers and read-only on-chain investigators. No signing, pricing, tax or complete-history claims. Vocabulary: workspace, wallet, capture, movement, evidence, coverage, job. Zero runtime dependencies, external fonts, trackers or CDNs.
