# Solana Flow

## Core value
A local-first Solana investigation workbench: exact net balance evidence with persistent provenance and explicit uncertainty.

## Current milestone: v2.0 Investigation Workbench
User explicitly delegated product decisions, implementation, verification, GitHub publication and release without checkpoints. The first release is genuine but too narrow. Success requires an operational application beyond generated reports.

Python >=3.11, zero runtime dependencies. SQLite multi-wallet workspace, immutable deduplicated captures, exact search and daily analytics, comparison, bounded current-token-account discovery, durable background jobs, loopback HTTP API, real browser application and static public explorer. Preserve v1 CLI/report compatibility.

Non-goals: custody/signing/trading, dollar pricing, tax, complete-history claims, public multi-tenant hosting. Dedicated gedanut identity and SSH remote only; no private activity or personal identity in public output.

## Evolution
v1.0 phases1–3 shipped (archived). v2.0 adds persistent operational workflows. More report charts would repeat the scope failure; a distributed indexer adds unnecessary hosting burden. SQLite + bounded worker provides useful engineering depth with one-command operation.
