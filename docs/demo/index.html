Read the movement, respect the limits.

SOL is the supplied wallet account’s post-balance minus pre-balance. SPL balances are summed across accounts explicitly owned by the wallet on each side of each transaction. Ownership changes affect attribution; missing owners create gaps. New and closed accounts use only the supplied side.

Inflow and outflow sum positive and negative net transaction changes. Internal movement can net to zero. Fees, rent, swaps, burns and wrapped SOL can affect these numbers. None are labeled as payments, income or tax events. Wrapped SOL stays a separate SPL mint. Token identifiers are untrusted; no symbol, logo or price is assumed.

Fees are counted only where the wallet is the fee payer. Incomplete metadata makes totals incomplete; they are observed movements, not a current portfolio balance. CSV protects textual fields against spreadsheet formulas; use JSON when exact identifier round trips matter.
